# About
My first long-term project
# Usage
## Controls
The player can choose their controls before starting the game. 
Except for the movement keys, there are three more inputs needed: attack, jump and defend (recommended to add them as consecutive keys).

## Abilities

There are a few simple key strings to use abilities:
- defend + any direction + attack / jump
- defend + attack
- defend + jump + attack
- last key may be held for a different result/ a charged version of the ability
- note: not every character has the maximum amount of abilities

# What I added
New Stages: There are 3 stages: in each one you battle against 10 characters from the roster one at a time. 
There is an extra stage where you battle all 30 as well.

Added characters from the community (more info in the *Credits* section) and adapted them to the version's mechanics.

New mechanics: 
- holding defence
- abilities that can hit opponents when lying on ground
- designed new abilities for some of the caracters
