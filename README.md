# About

My first long-term project and the one I have spent the most time on. This is a modified version of `Sx2: The Power of Emancipation`, a custom version of `Little Fighter 2`. The project focuses on expanding gameplay, introducing new mechanics, integrating community-created characters, and improving the overall player experience.

# Usage
## Controls
Players can customize their controls before starting the game.
In addition to the movement keys, three action keys are required: Attack, Jump and Defend (it is recommended to add them as consecutive keys).

## Abilities

Characters can perform abilities using specific key combinations:
- Defend + Any Direction + Attack / Jump;
- Defend + Attack;
- Defend + Jump + Attack;
- Holding the final key may trigger a stronger or alternate version of the ability.
- *Note: Not every character has an ability assigned to every possible key combination.*

# My Contributions
## New Survival Stages
- Added four custom survival stages:
  - Three stages where players fight 10 characters from the roster one after another;
  - One final challenge stage where players must defeat all 30 characters consecutively.

## Characters
- Added several community-created characters and adapted them to the mechanics of this game version.
- More information available in the *Credits* section.

## New mechanics
- Hold-to-defend functionality;
- Attacks capable of hitting opponents while they are lying on the ground;
- Designed new abilities for both existing and newly added characters.

## Bug Fixes and Balancing
- Fixed gameplay issues and adjusted character interactions to better fit the modified mechanics.
